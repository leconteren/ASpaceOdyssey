Claude Code Commits on GitHub

Three detection signals tracked via GitHub Search API · Jan 2025 – Feb 2026

Methodology: Data from GitHub Search API (/search/commits). Three signals: (A) claude.ai/code URL in commit message, (B) author-name:Claude — Claude as git author (Claude Code on Web), (C) "Co-authored-by: Claude" trailer — human author with Claude as co-author (CLI). Union estimated via inclusion-exclusion: A + B + C − A∩B − A∩C (B∩C ≈ 0). GitHub Search API total_count is approximate for large result sets. Feb 2026 is partial (1st–17th).
